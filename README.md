A dedicated, hands-on repository for practicing core Python programming concepts, standard library usage, and Python frameworks. Maintained by DecentCoders (Hridoy Hawladar), this repo houses a curated collection of standalone mini-projects, competitive programming exercises, and concept demos — all built 100% in Python. It is designed for both learning and refining Python skills, from beginner-friendly scripts to more advanced implementations, with room to expand into framework-specific practice.

## ✨ Key Features
- Curated collection of standalone Python mini-projects covering diverse real-world use cases
- Hands-on practice for core Python concepts: file handling, user input management, decorators, control flow, and more
- Competitive programming practice resources for ICPC-style problem-solving
- Iteratively refined code with bug fixes and UX improvements across all projects
- Beginner-friendly, well-structured code for easy learning and modification
- No mandatory external dependencies (all core projects use Python's built-in standard library)
- Organized folder structure for seamless navigation between different practice projects
- Built to support expansion for Python framework practice (Django, Flask, FastAPI, etc.)

## 🚀 Getting Started
### Prerequisites
You only need **Python 3.6 or higher** installed on your local machine. All core projects use Python's built-in standard library, with no additional external dependencies required.

### Run Locally
1. Clone the repository to your local machine:
```bash
git clone https://github.com/DecentCoders/practice.git
cd practice
```

2. Navigate to the folder of the project you want to run:
```bash
# Example: Navigate to the library management system
cd libraryManagement
```

3. Run the Python script for the project:
```bash
# Replace with the main script name for your chosen project
python3 main.py
```

4. For standalone scripts like `test.py`, run directly from the root folder:
```bash
python3 test.py
```
